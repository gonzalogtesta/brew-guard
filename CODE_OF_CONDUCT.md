# Code of conduct

This is a small open source project. Be decent to the people who use it and
work on it.

## What I expect

- Be respectful, also when you disagree. Argue about the code or the idea, not
  about the person.
- Assume good faith, and say so when you need more information.
- Keep reports and comments on topic. Don't paste other people's private data.

## What is not accepted

- insults, harassment, threats or discrimination
- publishing someone's private information
- spam or advertising that has nothing to do with the project
- anything else that makes it unsafe for people to take part

## Who this covers

Issues, pull requests, comments, discussions and any other place where people
talk about the project.

## What happens

I can edit or delete comments, close or lock threads, and block people who
break these rules. For something serious or personal, use the contact on my
GitHub profile instead of a public thread.

Security reports are a different thing, see [SECURITY.md](SECURITY.md).
